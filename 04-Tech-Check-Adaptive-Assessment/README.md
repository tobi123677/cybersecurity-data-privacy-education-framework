# Tech Check: Adaptive Cybersecurity Readiness Assessment

## Project Overview

Tech Check is a web-based cybersecurity-readiness assessment prototype developed as part of my broader K–12 Cyber Safety Framework initiative.

The application is designed to help students and educators identify strengths and potential knowledge gaps in everyday cybersecurity practices.

## Key Features

- Separate assessment pathways for students and educators/staff
- Scenario-based cybersecurity questions
- Adaptive question difficulty based on user responses
- Readiness results and learning recommendations
- Dashboard demonstrating how cybersecurity-readiness information can be presented

## Design and Development

I initially designed Tech Check's welcome page, user-selection screen, and assessment introduction screen using Figma.

I subsequently developed a working web prototype using Bubble. The application is being refined to improve question routing, readiness scoring, usability, and learning recommendations.

## Current Development Status

Tech Check is a prototype under development. Its dashboard includes synthetic demonstration data that should not be interpreted as actual school-wide assessment results.

The adaptive assessment and scoring methodology require further testing and validation before the application can be used to make reliable educational readiness evaluations.

## Next Development Steps

- Expand and refine role-specific question banks
- Test adaptive question pathways
- Improve readiness indicators and learning recommendations
- Expand Figma interface designs
- Conduct usability and accessibility testing
- Seek appropriate educator feedback before considering a school pilot

## Connection to the K–12 Cyber Safety Framework

Tech Check extends the broader framework by exploring how scenario-based assessments and data-informed results can help identify cybersecurity knowledge gaps and guide targeted educational support.
